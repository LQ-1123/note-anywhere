# NoteAnywhere — 灵感速记

按 **Alt+Q** 随时呼出一张顶置书写卡，记下灵感；再按 **Alt+Q** 收起，内容自动保存为 Markdown 文件。深浅主题跟随系统，界面克制，常驻系统托盘。基于 Electron + CodeMirror 6（与 Obsidian 同款编辑器内核）。

## 快捷键

| 按键 | 作用 |
| --- | --- |
| `Alt+Q` | 呼出 / 收起书写卡（收起即保存；可在设置中更改） |
| `Esc` | 收起并保存（弹窗/设置打开时优先关闭弹窗） |
| `Alt+N` | 新建一页（当前页自动保存） |
| `Alt+Del` | 删除当前页（弹窗确认） |
| `Ctrl+S` | 立即保存 |
| `Ctrl+B` / `Ctrl+I` | 粗体 / 斜体（包裹选中文字） |
| `Ctrl+=` / `Ctrl+-` | 字号增大 / 缩小（有选区调选区字号 10–28px，无选区调全局正文 14–18px） |
| 选中文字右键 | 格式菜单：加粗/斜体/字号/下划线/荧光笔/行内代码（智能切换） |
| `Tab` / `Shift+Tab` | 缩进 / 回退（一格 = 4 空格 = 2 个中文字宽，代码块内显示为 `·`）；**列表行整项缩进**（光标在项内任意位置都行）；表格内=单元格间跳转 |
| 表格内 `Enter` | 末行追加一行；空行上回车清空该行退出表格 |
| `/` | 唤出快速插入菜单（支持中文/英文/拼音过滤，`/bg` 即表格） |
| `Ctrl` + 点击链接 | 打开链接：网页交给系统浏览器，本地文件/图片用系统默认程序打开 |
| `Ctrl+V` | 粘贴文字/代码（自动识别语言加围栏）；剪贴板里是图片时存进笔记目录 `assets/` 并插入 `![]()` |

## 页面与文件

- **一页 = 一个 `.md` 文件**，保存在 `D:\desktop\insights`，以创建时间命名，首行作为标题
- 再次呼出自动回到**上次编辑页的光标位置**；每页独立记忆光标
- **左侧文档栏**：列出全部笔记，按最近编辑排序；点击切换（切换前自动保存）；悬停显示「×」删除（应用内统一风格确认弹窗）
- 空页收起自动清理；打字每 0.6 秒自动落盘，收起/退出强制保存

## Markdown 实时渲染

- 光标不在该行时隐藏 `##`、`**`、`[]()` 等标记，直接呈现标题/粗斜体/链接/引用效果；点回该行恢复源码
- `---` 渲染为分隔线
- **列表**：无序列表渲染为 `•`；有序列表**保留数字**（此前一律被画成 `•`）
- **多级自动编号（仅显示层）**：按嵌套层级依次显示 `1.` → `a.` → `i.`，更深再循环回数字，适合公文/大纲；
  例如 `1.` / 缩进后 `a.` / 再缩进 `i.`。Markdown 语法本身只有「数字.」一种有序列表记号，
  `a.`、`i.`、`1.1.` 都不是合法列表语法，所以**源码里仍是数字**，编号只作用于渲染结果
- 列表行不再画缩进圆点（否则会显示成 `· •`）

## 表格卡片（GFM 表格）

- 光标不在表格内时，整张表格渲染为**可交互表格卡片**：点击任意单元格跳入该格源码编辑（整表切换为源码态，浅底标识）
- 悬停表头列出现 `+ / ×`：在右侧插入列 / 删除此列；悬停行首出现 `+ / ×`：在下方插入行 / 删除此行；悬停卡片底部「＋ 行 / ＋ 列」整体追加
- 表格内 `Tab` / `Shift+Tab` 在单元格间跳转（自动跳过分隔行），末格 `Tab` 追加一行；`Enter` 追加行，空数据行上 `Enter` 清空退出
- 光标在表格上/下方行按退格/删除时自动落入首格/末格，避免把表格行拼坏；所有结构改动均为一次撤销步骤
- 兼容 `\|` 转义的竖线与列数不齐的行（自动补齐）；窗口隐藏期间表格以源码呈现，呼出后自动渲染（隐藏窗口的组件测量不安全，故有此门控）

## 代码块（VSCode 风格）

- 围栏内自动呈现为**编辑器卡片**：行号、边框圆角、当前行高亮、缩进圆点（一个 `·` = 4 空格 = 2 个中文字宽）
- 语法配色采用 **VSCode Dark+ / Light+**，跟随系统深浅切换
- **粘贴即着色**：粘贴裸代码自动包上带语言的围栏（识别 C++/Python/JSON/JS/HTML/Go/SQL）；粘贴无语言的围栏代码自动补标签
- 无语言的围栏显示灰色「纯文本」徽标作为提示
- 4 空格缩进的正文行按普通文字呈现（禁用 Markdown 缩进式代码块的代码样式，避免中文缩进误触发）

## 链接与图片

- **链接**：`[文字](https://…)` 在光标不在其中时渲染为带下划线的可点击文字，**按住 `Ctrl`（macOS 为 `Cmd`）点击**即跳转；网页交给系统浏览器，本地文件/图片交给系统默认程序打开
- 普通点击链接 = 把光标放进去，直接看到 `[]()` 源码来修改
- 跳转目标的解析：网络地址原样使用；本地路径相对于**当前笔记所在目录**（也可写绝对路径，如 `D:\pics\a.png`）；找不到文件则不动作
- **图片**：`![说明](路径或网址)` 在光标不在其中时直接渲染成图片，支持本地绝对路径、相对当前笔记的路径与 `https://` 网络地址；带空格的路径写成 `![说明](<a b.png>)`
- 图片加载失败会显示「图片无法加载」提示而不是留白；点击图片即回到源码编辑
- **粘贴图片**：截图（`Win+Shift+S` 等）或复制的图片直接 `Ctrl+V`，自动存成
  `笔记目录/assets/年-月-日_时-分-秒.png` 并在光标处插入 `![图片](assets/…)`，粘完立刻就是渲染态；
  纯文本/代码粘贴的行为完全不变。落盘失败会在右上角提示原因（格式不支持 / 超过 25MB）

## 设置

侧栏左下角 ⚙ 打开设置面板（托盘菜单也有入口），全部即时生效：

- **通用**：呼出热键（点击录入新组合）、主题（跟随系统/深色/浅色）、开机自启、笔记保存目录（更改/打开）
- **编辑器**：正文字号（14–18px）、Tab 宽度（2/4 空格）、Markdown 实时渲染、代码块行号、缩进圆点
- **窗口与数据**：窗口置顶、重置窗口位置、关于（版本 / 打开笔记目录 / 数据目录）

设置持久化在 `%APPDATA%\note-anywhere\config.json`（打包版为 `NoteAnywhere` 目录）。

## 托盘菜单（右键托盘图标）

- 打开书写区 / 新建一页 / 打开笔记文件夹 / 开机自启（开关）/ 退出（退出前自动保存）

左键点击托盘图标 = 呼出 / 收起。

## 更改保存目录

编辑 `%APPDATA%\note-anywhere\config.json`（打包版为 `%APPDATA%\NoteAnywhere\config.json`）：

```json
{ "notesDir": "E:\\my\\other\\folder" }
```

保存后重启应用生效。

## 安装与打包

- 安装包：`dist/NoteAnywhere-Setup-x.x.x.exe`（一键安装，默认开机自启）
- 便携版：`dist/NoteAnywhere-Portable.exe`

```bash
npm start          # 开发运行（自动构建前端 bundle）
npm run dist       # 打包（NSIS 安装版 + 便携版）
npm run smoke      # 冒烟自检（编辑器初始化 / 新建页 / 笔记目录 / 热键）
npm run diag       # 冒烟 + 渲染着色诊断（含表格卡片链路自检）
node tools/tag-audit.mjs        # 语法 tag 覆盖审计
```

> 冒烟通过 `tools/smoke-bootstrap.js` 在独立 userData + 临时笔记目录中运行，
> 不与常驻实例的单例锁/热键冲突，也不触碰真实笔记。远程桌面等无合成器的环境下
> 诊断段会优雅超时（`DIAG timeout`），不影响冒烟结论。

> 注：呼出热键特意避开 Ctrl+Space（中文 Windows 的输入法中英切换键），输入法切换习惯不受影响。
