# NoteAnywhere — 灵感速记

按 **Alt+Q** 随时呼出一张顶置书写卡，记下灵感；再按 **Alt+Q** 收起，内容自动保存为 Markdown 文件。深浅主题跟随系统，界面克制，常驻系统托盘。基于 Electron + CodeMirror 6（与 Obsidian 同款编辑器内核）。

## 快捷键

| 按键 | 作用 |
| --- | --- |
| `Alt+Q` | 呼出 / 收起书写卡（收起即保存） |
| `Esc` | 收起并保存（弹窗打开时优先关闭弹窗） |
| `Ctrl+N` | 新建一页（当前页自动保存） |
| `Ctrl+S` | 立即保存 |
| `Ctrl+B` / `Ctrl+I` | 粗体 / 斜体（包裹选中文字） |
| `Tab` / `Shift+Tab` | 缩进 / 回退（2 空格 = 一格，代码块内显示为 `·`） |
| `/` | 唤出快速插入菜单（支持中文/英文/拼音过滤） |

## 页面与文件

- **一页 = 一个 `.md` 文件**，保存在 `D:\desktop\insights`，以创建时间命名，首行作为标题
- 再次呼出自动回到**上次编辑页的光标位置**；每页独立记忆光标
- **左侧文档栏**：列出全部笔记，按最近编辑排序；点击切换（切换前自动保存）；悬停显示「×」删除（应用内统一风格确认弹窗）
- 空页收起自动清理；打字每 0.6 秒自动落盘，收起/退出强制保存

## Markdown 实时渲染

- 光标不在该行时隐藏 `##`、`**`、`[]()` 等标记，直接呈现标题/粗斜体/链接/引用效果；点回该行恢复源码
- `---` 渲染为分隔线，列表符渲染为 `•`

## 代码块（VSCode 风格）

- 围栏内自动呈现为**编辑器卡片**：行号、边框圆角、当前行高亮、缩进圆点（一个 `·` = 2 空格）
- 语法配色采用 **VSCode Dark+ / Light+**，跟随系统深浅切换
- **粘贴即着色**：粘贴裸代码自动包上带语言的围栏（识别 C++/Python/JSON/JS/HTML/Go/SQL）；粘贴无语言的围栏代码自动补标签
- 无语言的围栏显示灰色「纯文本」徽标作为提示

## 托盘菜单（右键托盘图标）

- 打开书写区 / 新建一页 / 打开笔记文件夹 / 开机自启（开关）/ 退出（退出前自动保存）

左键点击托盘图标 = 呼出 / 收起。

## 更改保存目录

编辑 `%APPDATA%\note-anywhere\config.json`（打包版为 `%APPDATA%\NoteAnywhere\config.json`）：

```json
{ "notesDir": "E:\\my\\other\\folder" }
```

保存后重启应用生效。

## 安装与打包

- 安装包：`dist/NoteAnywhere-Setup-x.x.x.exe`（一键安装，默认开机自启）
- 便携版：`dist/NoteAnywhere-Portable.exe`

```bash
npm start          # 开发运行（自动构建前端 bundle）
npm run dist       # 打包（NSIS 安装版 + 便携版）
npm run smoke      # 冒烟自检（编辑器初始化 / 新建页 / 笔记目录 / 热键）
npx electron . --smoke --diag   # 附带渲染着色诊断
node tools/tag-audit.mjs        # 语法 tag 覆盖审计
```

> 注：呼出热键特意避开 Ctrl+Space（中文 Windows 的输入法中英切换键），输入法切换习惯不受影响。
