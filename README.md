# NoteAnywhere — 灵感速记

按 **Alt+Q** 随时呼出一张顶置书写卡，记下灵感；再按 **Alt+Q** 收起，内容自动保存为 Markdown 文件。界面克制，深色书写，常驻系统托盘。

## 快捷键

| 按键 | 作用 |
| --- | --- |
| `Alt+Q` | 呼出 / 收起书写卡（收起即保存） |
| `Esc` | 收起并保存 |
| `Ctrl+N` | 新建一页（当前页自动保存） |
| `Ctrl+S` | 立即保存 |

## 使用逻辑

- **一页 = 一个 `.md` 文件**，默认保存在 `D:\desktop\insights`，文件名形如 `2026-10-03_18-32-05.md`（页面创建时间）。
- 再次呼出时，自动打开**上次编辑的那一页**，光标停在**上次书写的位置**。
- 首行会作为页面标题显示在顶栏（支持 `# 标题` 写法）。
- 整页为空时收起，文件会被自动清理，不会留垃圾文件。
- 输入过程中每 0.6 秒自动落盘一次，收起/退出前也会强制保存，不怕丢字。

## 安装

- 推荐安装 **`dist/NoteAnywhere-Setup-1.0.0.exe`**（一键安装，默认开机自启，开机后 Alt+Q 即可用）。
- 免安装可用 **`dist/NoteAnywhere-Portable.exe`**（单文件便携版）。

## 托盘菜单（右键托盘图标）

- 打开书写区 / 新建一页
- 打开笔记文件夹
- 开机自启（开关）
- 退出（退出前自动保存）

左键点击托盘图标 = 呼出 / 收起。

## 更改保存目录

编辑 `%APPDATA%\note-anywhere\config.json`：

```json
{ "notesDir": "E:\\my\\other\\folder" }
```

保存后重启应用生效。

> 注：呼出热键特意避开了 Ctrl+Space（中文 Windows 的输入法中英切换键），输入法切换习惯不受影响。
